## Исправленные дефекты

### QA-01 — потеря фокуса после закрытия диалога (средняя серьёзность)

Воспроизведение: открыть главную, сфокусировать header «Записаться», Enter, пройти Tab по диалогу, Escape. Ожидалось возвращение на кнопку; фактически активный элемент терялся. Причина: React удаляет dialog до того, как нативный close восстанавливает opener.

Исправление: `src/components/dialog.tsx` запоминает opener до showModal и возвращает фокус при cleanup, только если элемент ещё подключён к DOM; восстановление overflow сохранено. Регрессия keyboard проверяется в трёх браузерах. В Windows WebKit естественный Tab пропускает ссылки: skip-link проверяется explicit focus + Enter с annotation; первый Tab проверен в Chromium/Firefox.

Доказательство первоначального FAIL: `.artifacts/qa/2026-11-08T07-47-39-047Z-quick/browser/results/e2e-journeys-keyboard-open-1a370--and-restores-trigger-smoke-chromium/trace.zip` и `test-failed-1.png`. Повторная проверка основного набора PASS.

### QA-02 — HTTP 404 файлов предзагрузки Windows-экспорта (средняя серьёзность)

Воспроизведение: собрать на Windows и открыть gallery/quiz, наблюдать запросы `__next.portfolio.__PAGE__.txt` и `__next.portfolio.$d$id.__PAGE__.txt`. Ожидалось HTTP 200; фактически экспорт Next сохранял часть имён во вложенных каталогах с Windows-разделителями, хотя клиент запрашивает плоские имена с точками. Страницы могли открываться через fallback, но ошибки сети/консоли оставались.

Исправление: `scripts/normalize-export.mjs`, запускаемый после `next build`, добавляет канонические файлы в сгенерированный out. Исходный код Next/node_modules не патчится, исходные экспортированные файлы сохраняются. Два unit-теста проверяют вложенные/плоские варианты; все browser guard повторно прошли. `preview` дополнительно получил настраиваемый PORT для изоляции тестов.

Доказательства до исправления: `.artifacts/qa/2026-11-08T07-47-39-047Z-quick/browser/results.json`, вложения `browser-diagnostics` и traces пяти упавших smoke-сценариев.
